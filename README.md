# RT Cars Website

A simple website project for RT Cars, focused on presenting the brand, featured vehicles, and contact information in a clean and responsive experience.

## Overview

This repository is intended to hold the source code, assets, and supporting files for the RT Cars website. It currently serves as the project foundation while the site content and implementation are being developed.

## Getting started

1. Clone the repository.
2. Open the project in your preferred editor.
3. Install dependencies and start the local development server using the project toolchain once the app files are added.

Example:

```bash
git clone https://github.com/rtcarsjp/rt-cars-website.git
cd rt-cars-website
npm install
npm run dev
```

## Project status

This repository is in its initial setup stage and will continue to evolve as the website structure, pages, styling, and content are added.
